# docs/

Thirteen documents, none of them required reading to run COM. This index says
what each one answers and whether it is current, so you can open the one you
want and ignore the rest.

The short version: **[`../MATLAB_Correlation_Review.md`](../MATLAB_Correlation_Review.md)
is the evidence**, and [`FIX_SUMMARY.md`](FIX_SUMMARY.md) is the history of every
change that moved a number. Everything else is detail behind those two.

## How accurate is this port, and why should I believe it

| document | what it answers | state |
|---|---|---|
| [`../MATLAB_Correlation_Review.md`](../MATLAB_Correlation_Review.md) | the 208-case comparison against the MATLAB reference: method, per-case results, what still differs and why | current |
| [`FIX_SUMMARY.md`](FIX_SUMMARY.md) | every correctness fix that changed a number, with its evidence and what it bought | current, maintained |
| [`MATLAB_4p16p0_IMPACT.md`](MATLAB_4p16p0_IMPACT.md) | what changes if you run 4p16p0 instead of 4p15p0, measured on the same 208 cases | current |
| [`MATLAB_4p16p0_CHANGES.md`](MATLAB_4p16p0_CHANGES.md) | the upstream diff between the two releases, generated by `tools/matlab_version_diff.py` | current |
